# ADR 0006：M3 ADC 使用 Timer_B0.1 触发

## 文档说明

本文档记录 M3 首次真实采集中 ADC 零转换问题的最小修正决定，适用于
MSP430F5529 的 200 kS/s、2048 点采集路径。它补充 M3 采集设计，不改变
TUSS4470 配置、Burst 数量、DMA 数据布局或主机协议。

## 现象与证据

两次经授权的单次采集均通过 IO2 回环并成功发送 `CAPTURE_ONCE`，但设备返回
`captured_samples=0`、`dma_remaining=2048`。后续隔离测试证明ADC和DMA均正常；
该结果来自错误地用块完成后自动重装的`DMA0SZ`推算完成点数，不能作为ADC零转换
证据。因此TB0.1改动不是根因修复，只保留为更明确的定时触发实现选择。

## 决定

- 使用 `TB0CCR0 = sample_interval_ticks - 1` 定义 120 个 SMCLK tick 的采样周期；
- 使用 `TB0CCR1 = 1` 和 `TB0CCTL1 = OUTMOD_3`，每周期产生一个明确的
  TB0.1 上升沿；
- ADC12 触发源改为 `ADC12SHS_3`（TB0.1）；
- 停止采集时显式关闭 TB0.1 输出模式；
- 保持 200 kS/s、2048 点、64 点预触发、DMA0/DMA1 和单脉冲 Burst 不变。

## 备选方案

继续使用 TB0.0/CCR0 翻转模式需要依赖 CCR0 同时作为周期边界和内部输出的特殊
行为，实机已经稳定表现为零转换。软件触发可以绕过问题，但不能验证正式的定时
采样路径。TB0.1 是数据手册明确映射到 `ADC12SHS_3` 的独立比较输出，因此作为
最小且可验证的修正。

## 验收

静态测试必须确认新的 TB0.1配置，并要求DMA0中断提供独立的完整块证据，禁止以
完成后自动重装的`DMA0SZ`推算成功点数。完整固件构建和离线回归通过后，才允许
在7 V断电状态刷写；真实验收仍只执行一次单脉冲采集，成功标准是收到恰好2048
个未经插值的ADC原始样本。
