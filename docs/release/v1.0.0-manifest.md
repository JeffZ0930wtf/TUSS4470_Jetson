# V1.0.0 release manifest

## Document overview

This manifest binds the TUSS4470 acquisition module V1.0.0 source candidate to
its firmware, container, dependency, Windows, Jetson, and physical-capture
evidence. It is the compact index for the accepted release baseline. The
acceptance summary explains the supported claims; the known-limitations
document defines what this release does not claim.

## Public commands

- `usac-core`: Web/API/Core service; physical deployment passes
  `--backend bridge` explicitly.
- `usac-bridge`: USB CDC, protocol forwarding, reconnect, and durable pending
  spool service.
- `usac-cli`: REST client for configuration, acquisition, sessions, history,
  and sample download.
- `usac-export`: direct offline SQLite inspection and `.usac`, `.u16le`, and
  `.json` export without Core.

## Accepted release boundary

This is a supervised experimental acquisition release, not an unattended
production BMS. Timing is uncalibrated; the 10,000 ms lease compromise,
non-lossless high-rate periodic scheduling, reconnect limitations, and absent
external-network hardening remain accepted. See
[V1.0.0 known limitations](v1.0.0-known-limitations.md).
