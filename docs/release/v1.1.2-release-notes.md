# V1.1.2 发布说明

## 文档说明

本文记录 V1.1.2 网页补丁的操作变化、实机验收范围与部署方式。适用于采集控制台和
Jetson 主机；[V1.1.1 发布说明](v1.1.1-release-notes.md)保留之前的缓存修复与实测证据。

## 网页改动

- **实验／分组弹窗**：在相应下拉框旁新建或编辑。编辑回填已有名称、备注和分组电芯编号；
  取消不写入，失败保留输入。改名不改变 ID、采集归属或已有波形。
- **历史记录两级筛选**：「全部记录」包含未分组记录；选「按实验筛选」后直接显示所属分组，
  默认看全部分组，也可点单组查看。换实验会重置组筛选，历史筛选不会更改下一次采集分组。
- 本页保存编辑后，已加载记录立即显示新标签；刷新历史时以 API 返回的最新名称和电芯编号为准，
  不用旧的浏览器分组缓存覆盖。
- 中英文界面均支持以上操作。REST API 仍为 v1，SQLite 结构、采集协议、固件 `0.2.0.2`、
  安全门禁和第三方依赖锁定不变，无需迁移数据或刷写。

## 验收范围

- V1.1.2 Windows 聚合门禁通过：261 项 Python 测试、Node 网页回归、固件编译及安全静态检查。
  Jetson 启动与聚合测试脚本的 shell 语法检查通过。固件未烧录。
- 本地浏览器验证弹窗新建、回填编辑、Esc 取消、重新打开后数据保留，以及全部、实验、组
  筛选。独立模拟库的未分组记录仍只在全部记录中可见。
- Jetson 使用网页候选 `tuss4470-acquisition-core:1.1.1-history-161526dd` 验收，
  Core 镜像 ID 为 `sha256:60b1364ee20d71aa8c6f0ca5dba25aa2b1b9ed578625d06d507ccbe244f7b16e`。
  实际浏览器验证全部 13 条、两实验各 2 和 11 条、点击组和切换实验；采集绑定不变。
  正式库 13 条采集、2 个实验、2 个组及 21 个会话与切换前快照逐行一致，Bridge 待交付为 0。
  设备为 `NORMAL / IDLE`，采集序号保持 5。这次筛选验收未触发采集、改归属、Apply 或刷写。
  现场库当时没有未分组记录；此分支在本地模拟器验证，不将示例数据写入正式库。

  实机网页验收使用上述候选镜像。发布时保留在线 Core 和 Bridge，本轮未额外进行实采。

## 运行与回退

默认镜像 `tuss4470-acquisition-core:1.1.2`，与现有数据目录兼容。发布和同步源码不会自行
替换在线容器。按 [Jetson 部署指南](../deployment/jetson.md)在空闲并完成供电确认后切换；
回退只换镜像，不覆盖 SQLite。Windows 经隧道访问 `http://127.0.0.1:18080/`。
