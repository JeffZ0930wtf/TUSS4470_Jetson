# V1.0.0 pre-consolidation baseline

## Document overview

This document freezes the accepted source and firmware evidence immediately
before the V1 naming and release consolidation. It answers which revision,
toolchain, loadable firmware image, prior hardware evidence, and known limits
the consolidation must preserve. It applies to Task 1 of the V1 release plan
and is the comparison authority for the later source-name and build-script
renames. The operational release documents and final manifest supersede it for
day-to-day use; the archived M6 records remain the hardware-verification
evidence.

## Firmware extraction method

The accepted pre-rename firmware was built without flashing or opening a
serial port:

```powershell
scripts/build-firmware-m5.ps1
```

Build output:

`firmware/build/m5/usac-m5-first-version.elf`

The canonical comparison image was generated with:

```powershell
msp430-elf-objcopy.exe -O ihex --gap-fill 0xFF <input.elf> <output.hex>
```

The same `msp430-elf-objcopy.exe` binary, output format, load addresses, and
`0xFF` inter-section hole-fill rule must be used for all later comparisons.
The Intel HEX comparison requires both SHA-256 equality and no line difference.
ELF container hashes alone are not treated as proof of loadable-code equality.

## Accepted limitations carried into V1

- Captures retain `TIMING_UNCALIBRATED`; calibrated TOF and event timing still
  require external timing instruments.
- The exposed transport CRC diagnostic is a fixed residue of an already
  CRC-protected frame and is not a content fingerprint. Native frame CRC and
  terminal-decision SHA-256 remain effective.
- The accepted 10,000 ms lease accommodation and non-lossless 5 Hz scheduling
  result remain first-version limits. Long unattended operation is not a V1
  claim.
- A deliberately disrupted stale bridge session required a Core restart;
  replacement-session and handshake-timeout hardening remain later work.

These limits do not alter hardware safety, raw-sample identity, explicit save
semantics, or the bounded M6 verification. They prohibit presenting V1 as a
production-ready unattended acquisition system.
