# V1.0.1 Release Plan

> **For agentic workers:** Use `executing-plans` to complete this release inline. The user has authorized integration, push, and the next release tag.

## Document overview

This plan publishes the completed Jetson launchers as V1.0.1. It records the
version decision, release scope, and offline checks, and complements the V1.0.0
artifact manifest and the V1.0.1 release notes.

**Goal:** Publish the current launcher implementation on GitHub main with an annotated `v1.0.1` tag.

**Architecture:** Keep the two launchers from `3b83ee7`: Jetson owns Compose startup; Windows invokes it through SSH and opens the local tunnel/browser. Preserve the accepted acquisition runtime and firmware.

**Tech Stack:** PowerShell, POSIX shell, Python 3.12/uv 0.12.5, Git.
